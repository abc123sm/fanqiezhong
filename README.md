# 番茄钟 (Go fanqiezhong)

这是一个基于神经可塑性原理设计的极简番茄钟程序，专为 OBS 直播或个人深度工作设计。

> **设计灵感与科学依据**：本项目参考了 Andrew Huberman 博士的公开文章 [Teach & Learn Better With a “Neuroplasticity Super Protocol”](https://www.hubermanlab.com/newsletter/teach-and-learn-better-with-a-neuroplasticity-super-protocol)，通过科学的随机微休息间隔（间隙效应）、90 分钟超日节律边界与 NSDR 长休息窗口提升学习与深度工作效率。
> - 📖 **纯深度学习指南**：九步核心原理提炼、程序参数映射及配套用法请参阅 **[《神经可塑性超级协议与设计映射》](./docs/neuroplasticity-protocol.md)**。
> - 🏋️ **文体两开花玩法（意外发现）**：程序完成后意外发现，`90~150 秒` 随机间隔恰好覆盖肌肉磷酸肌酸（ATP-CP）75%~87.5%+ 的黄金恢复期！将微休息调至 `20~35 秒` 即可兼顾随机间歇爆发力训练与兴趣学习，详见 **[《进阶玩法：文体两开花的体能×学习交叉协议》](./docs/athletic-dual-mode.md)**。

## ✨ 核心特性

-   **科学的随机间隔**：小循环时长可在基础时间上随机浮动，模拟真实神经系统的适应性，避免大脑对固定节奏产生疲劳。
-   **多级循环结构**：
    *   **小循环 (Micro)**：基础专注单元（如 2 分钟 ± 随机偏移）。
    *   **中循环 (Meso)**：由多个小循环组成（如 25 分钟）。
    *   **大循环 (Macro)**：由多个中循环组成（如 3 组），完成后进行长休息。
-   **极简无文字阶段配色**：界面仅保留进度条与 `MM:SS` 等宽倒计时数字，通过颜色直观区分阶段：
    *   🟩 **翠绿 (`#4CAF50`)**：小循环专注
    *   🟨 **琥珀黄 (`#FFB300`)**：小循环微休息
    *   🟦 **清爽青 (`#26C6DA`)**：中循环休息
    *   🟪 **紫罗兰 (`#AB47BC`)**：大循环长休息
    *   🔵 **科技蓝 (`#2196F3`)** *(第二行)*：当前中循环整体进度
-   **OBS 直播原生透明叠加**：Web 界面默认原生透明背景，基于 SSE 事件流驱动，平时零轮询开销；GUI 窗口原生支持 Windows 高分屏（HiDPI）锐利渲染。
-   **自律控制哲学（无暂停）**：不设暂停——一旦中断即应重新进入心流，仅提供**从 0 重新开始**与**安全退出**控制。
-   **内存预解码音效与内置兜底**：默认提示音已内嵌至单文件可执行程序中（同时支持外部 `Sounds/` 目录同名文件覆盖自定义），播放零磁盘 I/O、零计时阻塞。
-   **极低资源占用**：GUI 版本限制为 1 TPS，Web 无头版本零显存占用。

## 🚀 版本选择

我们提供了 5 种独立运行模式，既可按需下载对应的单模式压缩包，也可直接下载包含全部 5 种模式可执行文件的**全量合集包 (`time_clock_all.zip`)**（共用同一份配置与音效，方便随时切换）。下载压缩包后解压即可使用。

### 1. 纯净窗口版 (`time_clock_gui_only`) - **推荐个人使用**
*   **包含文件**：`time_clock_gui_only.exe`
*   **界面**：独立小窗口，显示进度条和倒计时。
*   **控制**：窗口聚焦时按 `R` 键从 0 重新开始；点击右上角 `×` 退出程序。
*   **适用**：桌面挂件，不需要连接 OBS 浏览器源的用户。

### 2. 窗口+Web版 (`time_clock_gui_web`) - **推荐直播使用 (方案 A)**
*   **包含文件**：`time_clock_gui_web.exe`
*   **界面**：独立小窗口 + 本地 Web 服务器 (默认 `127.0.0.1:8080`)。
*   **适用**：主播，需要同时在副屏监控时间和在直播间展示时间。

### 3. 隐形 Web 版 (`time_clock_web_headless`) - **推荐直播使用 (方案 B)**
*   **包含文件**：`time_clock_web_headless.exe`
*   **界面**：**无任何窗口**，无任务栏图标，无控制台黑框。
*   **特点**：纯后台静默运行。
*   **控制**：浏览器访问 `http://127.0.0.1:8080/control` 可一键**从 0 重新开始**或**退出程序**（无需打开任务管理器）。

### 4. 终端版 (`time_clock_term_only`)
*   **包含文件**：`time_clock_term_only.exe`
*   **界面**：命令行黑框，打印实时阶段日志，按 `Ctrl+C` 安全退出。

### 5. 终端+Web版 (`time_clock_term_web`)
*   **包含文件**：`time_clock_term_web.exe`
*   **界面**：命令行黑框 + Web 服务，适合查看详细运行日志与调试。

## ⚙️ 配置说明

在程序同级目录中找到 `config.json` 文件进行修改（修改后重启生效）：

```json
{
    "小循环基础时间秒": 120,
    "小循环随机偏移秒": 30,
    "小循环休息时间秒": 10,
    "中循环总时间分": 25,
    "中循环休息时间分": 5,
    "中循环组数": 3,
    "大循环休息时间分": 30,
    "监听地址": "127.0.0.1",
    "端口": 8080
}
```

> 说明：`"监听地址"` 为可选项，默认绑定 `"127.0.0.1"` 以免触发 Windows 防火墙公用网络弹窗；如需局域网其他设备访问可改为 `"0.0.0.0"`。

## 🎥 OBS 最佳实践

### 方式一：采集 Web 界面 (推荐)
1.  运行 **窗口+Web版** 或 **隐形 Web 版**。
2.  在 OBS 中添加 **"浏览器" (Browser)** 源。
3.  URL 填写：`http://127.0.0.1:8080`（如需黑底可在末尾加 `?bg=000`）。
4.  宽度设为 `600`，高度设为 `120`。
5.  页面默认即为**原生透明背景**，无需添加色值键滤镜即可无锯齿叠加在直播画面上。
6.  需要归零重来或关闭后台程序时，在普通浏览器打开 `http://127.0.0.1:8080/control` 即可操作。

### 方式二：采集窗口
1.  运行 **纯净窗口版** 或 **窗口+Web版**。
2.  在 OBS 中添加 **"窗口采集" (Window Capture)**，选择 `"番茄钟状态"` 窗口。
